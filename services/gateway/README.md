# Gateway

Єдина точка входу для фронтенду. Власної бази й контракту не має.

## Що робить

1. **Маршрутизує** за першим сегментом: `/api/<блок>/…` → сервіс блоку,
   префікс `/api` зрізається. Карта блоків — змінна `UPSTREAMS`.
2. **Перевіряє токен** (RS256) за публічним ключем з JWKS блоку `identity`.
   Без токена відкриті тільки `POST /api/identity/auth/login` і
   `GET /api/identity/.well-known/jwks.json` — точний збіг методу й шляху.
3. **Каже сервісу, хто прийшов**: `X-User-Id`, `X-User-Role`,
   `X-User-Permissions`. Такі самі заголовки з вхідного запиту зрізаються —
   підробити їх ззовні неможливо.
4. **Проставляє `X-Request-Id`** (або зберігає вхідний) — запит можна
   простежити по логах усіх сервісів.

Чого **не** робить: не перевіряє конкретні права. `customers.write` чи ні —
вирішує сервіс `customers`. Gateway відповідає лише на питання «хто це».

## Відповіді самого gateway

| Код | Коли |
|---|---|
| 401 | немає токена, прострочений, чужий підпис, невідомий `kid` |
| 404 | блок не підключений у `UPSTREAMS` |
| 400 | `..` у шляху |
| 502 | сервіс блоку не відповідає на зʼєднання |
| 504 | сервіс не встиг за `UPSTREAM_TIMEOUT_SECONDS` |

Тіло завжди `{"detail": "…"}` — як у сервісів, фронт показує його як є.

## Підключити новий блок

Один рядок у `UPSTREAMS`, код не змінюється:

```bash
UPSTREAMS='{"identity": "http://identity:8002", "customers": "http://customers:8001", "vehicles": "http://vehicles:8003"}'
```

## Відмовостійкість

- JWKS кешується в памʼяті. identity впав — ті, хто вже увійшов, працюють далі;
  не працюють тільки вхід і `/api/identity/*`.
- Невідомий `kid` (ротація ключа) — JWKS перечитується, але не частіше ніж раз
  на `JWKS_REFRESH_COOLDOWN_SECONDS` (5 с). Інакше потік сміттєвих токенів
  перетворюється на DoS для identity.
- Тіла запитів і відповідей стрімляться, відповідь іде байт у байт — зокрема
  стиснена, без розпакування.

## Запуск

```bash
cd services/gateway
uv sync --group dev
uv run uvicorn app.main:app --reload --port 8000
```

Значення за замовчуванням розраховані на локальний запуск: identity на `:8002`,
customers на `:8001`. Дев-сервер каркаса проксіює `/api` сюди.

## Перевірки

```bash
uv run pytest        # 17 тестів, сервіси й JWKS підмінені, мережа не потрібна
uv run ruff check .
uv run mypy app
```

## Що лишилось зробити

- Rate limit — насамперед на `/api/identity/auth/login`.
- Агрегація відповідей кількох сервісів (див. `docs/architecture.md`, розділ 4).
- Метрики: латентність і коди відповідей по блоках.
