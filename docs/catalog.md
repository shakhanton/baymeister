# Блок `catalog`

Що автосервіс продає: роботи з нормо-годинами, вартість нормо-години з
історією і каталог запчастин із цінами.

## Чотири артефакти блоку

| Артефакт | Де лежить | Що це |
|---|---|---|
| Контракт | [`contracts/catalog.yaml`](../contracts/catalog.yaml) | OpenAPI 3.1, публічний інтерфейс |
| Сервіс | [`services/catalog/`](../services/catalog/) | FastAPI + власна схема в PostgreSQL |
| Фронтенд-модуль | [`packages/modules/catalog/`](../packages/modules/catalog/) | роботи зі ставкою, запчастини |
| Документація | цей файл | ціноутворення, межі, події |

## Що блок віддає

| Метод | Шлях | Право | Що робить |
|---|---|---|---|
| `GET` | `/catalog/labor-rate` | `catalog.read` | поточна ставка; `?at=` — ставка, що діяла тоді |
| `PUT` | `/catalog/labor-rate` | `catalog.write` | нова ставка з моменту `effective_from` (за замовч. — зараз) |
| `GET` | `/catalog/labor-rate/history` | `catalog.read` | усі ставки, від нових до старих |
| `GET` | `/catalog/services` | `catalog.read` | роботи з поточною ціною; пошук, категорія, архів |
| `POST` | `/catalog/services` | `catalog.write` | додати роботу |
| `GET`/`PATCH` | `/catalog/services/{id}` | read / write | одна робота / змінити |
| `POST` | `/catalog/services/{id}/archive` | `catalog.write` | мʼяке видалення |
| `GET` | `/catalog/parts` | `catalog.read` | каталог запчастин; пошук за артикулом, назвою, брендом |
| `POST` | `/catalog/parts` | `catalog.write` | додати запчастину |
| `GET`/`PATCH` | `/catalog/parts/{id}` | read / write | одна запчастина / змінити |
| `POST` | `/catalog/parts/{id}/archive` | `catalog.write` | мʼяке видалення |

## Як рахується ціна роботи

```
ціна = fixed_price                      якщо задана     → price_source: "fixed"
     = norm_hours × ставка, до копійки  якщо ставка є   → price_source: "norm_hours"
     = null                             ставки ще немає → price_source: "unknown"
```

Ціна рахується при читанні, а не зберігається: нова ставка одразу змінює
весь прайс. Округлення — до копійки, половина вгору (`0.15 × 333.33 = 49.9995 → 50.00`).

**Ставка має історію.** `PUT` не змінює стару ставку, а додає нову з власним
`effective_from`. Ставку можна запланувати наперед: вона почне діяти в
зазначений момент. `GET /catalog/labor-rate?at=…` відповідає, яка ставка
діяла тоді, — для нарядів, відкритих до зміни.

**`work-orders` цін не перераховує.** Додаючи роботу чи запчастину в наряд, він
бере ціну на цей момент і зберігає її в себе. Зміна прайсу не переписує старі
наряди.

## Гроші

- Скрізь `Decimal`, ніде `float`. У базі — `numeric(11,2)`.
- Назовні — **рядок** із рівно двома знаками: `"850.00"`. JSON-число будь-який
  клієнт може прочитати у float і загубити копійку.
- Приймається людський ввід: `"850"`, `"850,5"` → `"850.50"`. Від'ємні, три
  знаки після коми, `1e3` — 422.
- Фронт не перетворює рядок на число навіть для показу: `"1350.00"` →
  «1 350,00 ₴» рядковими операціями.

## Межі

**Коди й артикули нормалізуються.** Без пробілів, у верхньому регістрі:
«oc 90» і `OC90` — одне. Бренд — у верхньому регістрі.

**Один артикул — різні бренди.** `OC90` є і в MAHLE, і в KNECHT: унікальна пара
артикул + бренд, а не артикул.

**Унікальність — серед активних.** Код архівної роботи можна використати знову.
Архівні роботи й запчастини лишаються доступними за ідентифікатором — старі
наряди на них посилаються.

**Залишків тут немає.** Скільки фільтрів на складі — блок `inventory`. Каталог
знає лише, що це за деталь і скільки вона коштує.

## Що блок публікує

| Подія | Коли | Хто слухає і навіщо |
|---|---|---|
| `labor_rate.changed` | нова ставка | `analytics` — динаміка ціни нормо-години |
| `service.created` / `updated` / `archived` | зміни робіт | `documents` — прайс для друку |
| `part.created` / `updated` / `archived` | зміни запчастин | `inventory` — картка номенклатури |
| `part.price_changed` | змінилась ціна запчастини | `analytics`; `inventory` — переоцінка |

## Запуск

```bash
docker compose up -d postgres
cd services/catalog
cp .env.example .env
uv sync --group dev
uv run alembic upgrade head
uv run uvicorn app.main:app --reload --port 8004
```

## Перевірки

```bash
cd services/catalog
uv run pytest         # 19 тестів
uv run ruff check .
uv run mypy app

cd ../..
pnpm --filter @baymeister/module-catalog typecheck
```

У тестах база — SQLite, а вона не знає регістру кирилиці в `ILIKE`. Пошук
«фільтр» → «Фільтр» перевірено на PostgreSQL.

## Що лишилось зробити

- Кілька прайс-листів (роздріб, для корпоративних клієнтів) — зараз один.
- Імпорт каталогу запчастин від постачальника (CSV / API) — разом із
  блоком `procurement`.
- Нормо-години за маркою й моделлю авто: заміна ГРМ на Golf і на Passat
  займає різний час.
